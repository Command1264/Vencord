# Vencord Fork: BetterSliders

This fork develops the BetterSliders plugin while preserving upstream Vencord behavior.

## Required routing

- For BetterSliders planning or implementation, read `docs/better-sliders/ROADMAP.md`,
  `CONTEXT-MAP.md`, and the BetterSliders context it references.
- Before changing a subsystem, read relevant decisions under `docs/adr/` when present.
- Follow the repository's existing build and contribution conventions. Do not present
  AI-authored work as eligible for an upstream Vencord contribution; see `CONTRIBUTING.md`.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five-role triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This fork uses a multi-context map with a BetterSliders-local context. See
`docs/agents/domain.md`.
